# 影石 Insta360 全景素材:视角语言与盘点

用于 Phase 2(素材盘点)和 Phase 3(写剪辑方案)。全景素材的核心优势:**一段素材可出多个视角**,剪辑方案的 reframe 标注就是告诉剪辑者"这一段用哪个视角"。

## 全景独有视角(reframe 标注词表)

在 edit_plan 的 `reframe` 字段使用这些标准词,剪辑时对应 Insta360 Studio/App 的取景操作:

| 标注词 | 视觉效果 | 适用场景 | 剪辑定位 |
|---|---|---|---|
| `小行星` | 画面卷成球体,人站在星球上 | 开场冲击、地点展示 | 钩子/转场 |
| `反小行星`(隧道) | 天空卷成隧道,坠入感 | 开场、加速冲刺段 | 钩子/高潮 |
| `FPV` | 低视角贴地前冲,穿越机感 | 行进、穿越人群/门洞 | 推进节奏 |
| `第三人称跟随` | 隐形自拍杆,背后跟拍主角 | 主体运动全过程 | 叙事主线 |
| `俯瞰` | 高空无人机俯视感 | 大场景、队形、地形 | 信息交代 |
| `甩切` | 视角快速甩向另一方向(whip pan) | 卡 beat 切镜 | 节奏点 |
| `子弹时间` | 绕主体环绕+慢动作 | 高光瞬间(跳跃/动作顶点) | 高潮定格 |
| `滚动` | 画面整体旋转(roll) | 过渡、制造眩晕动感 | 转场 |
| `镜像翻转` | 水平翻转构图 | 与上一段形成对仗 | 节奏变化 |
| `正拍` | 普通平面取景(广角/线性) | 口播、特写细节 | 信息段 |

## 全景剪辑原则

1. **视角反差即节奏**:相邻两段视角差异越大(小行星→FPV),冲击越强;同视角连排会浪费全景优势
2. **甩切必须卡 beat**:视角甩动落在 onset_peaks 上,否则显乱
3. **小行星类视角慎用时长**:1-2s 足够,超过 3s 观众眩晕
4. **第三人称跟随是叙事锚点**:花字/字幕主要挂在跟随视角段
5. **子弹时间只给最高光**:全片 1 次,多了贬值
6. 导出规格:竖屏 1080x1920、30fps(抖音主流)

## 素材盘点模板(footage_inventory.md)

对每段素材(看抽帧)记录:

```markdown
### <素材文件名>
- 时长:xx s | 运动状态:行走/跑步/骑行/静止/车载
- 内容:一句话(谁在哪做什么)
- 画质/光线:白天顺光/夜景噪点多…
- 可用视角:第三人称跟随✓ 小行星✓ FPV✗(无行进感)
- 高光时刻:xx s 处(跳跃顶点/回头/冲线)
- 避雷:xx-xx s 画面糊/路人正脸/自拍杆穿帮
```

## 盘点红线
- .insv 原始文件不能直接进流程:必须先在 Insta360 Studio/App 里导出 mp4(可在导出时先做一版粗 reframe)
- "可用视角"必须基于抽帧实际画面判断,禁止凭空标注
- 高光时刻要给秒数,这是 Phase 3 排时间线的锚点
